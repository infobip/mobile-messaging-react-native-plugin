# Example app

This app demonstrates the plugin against React Native 0.86.0 and links the local workspace package via `file:../`.

## Setup

From this folder, install dependencies:

```bash
npm install
```

## Android verification

From `Example/android/`, run:

```bash
./gradlew assembleDebug
```

## Run the app

To start Metro and launch the app on Android, run:

```bash
npm run android
```
